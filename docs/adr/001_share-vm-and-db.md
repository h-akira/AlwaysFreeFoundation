# 001 1 つの VM と 1 つの DB に相乗りさせる

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）

## 背景

OCI の Always Free は、VM や DB の **個数** で枠が決まっている（[references/oci-free-tier.md](../references/oci-free-tier.md)）。個人開発のプロジェクトは小さく、1 つに 1 組を使うと、枠をすぐに使い切り、資源の大半が遊ぶ。

## 決定

- 少ない VM と 1 つの DB に、全プロジェクトを相乗りさせる。
- 次は作らない: 既製の PaaS（Dokku・Coolify など）・Kubernetes・Nomad、共通のログイン（SSO）、自前の監視の仕組み（Prometheus など）、ステージング環境、頻度の低いことを自動で見張る仕組み（DB の版のずれの検出・A1 の取り直しなど）。

## 理由

- 1 プロジェクト 1 組では、載せられるプロジェクトが数個で止まる。
- 作らないものは、どれも部品を増やす。個人用の基盤では、仕組みの単純さを優先する（自分で見て直せることを保つ）。

## 引き換え

- VM が落ちると全プロジェクトが止まる。個人用なので許す。
