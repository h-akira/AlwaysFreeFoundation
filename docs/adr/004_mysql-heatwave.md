# 004 DB は MySQL HeatWave を共有する

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）

## 背景

VM をステートレスにするには、DB を VM の外に置く必要がある。Always Free のマネージドな DB は、MySQL HeatWave（1 個）と Autonomous Database（2 個）（[references/oci-free-tier.md](../references/oci-free-tier.md)）。

## 決定

- MySQL HeatWave の Always Free を、全プロジェクトで共有する。プロジェクトごとにデータベースとユーザを分ける。
- 手元では公式の `mysql` のコンテナを、本番と同じ版・同じ設定で動かす。
- 保守のたびに最新の版へ上がるので、手元の版を追いかける。バックアップが 1 日分しかないので、基盤が毎日ダンプを取って補う。
- 止まる条件が公式文書に見つからなかったので、基盤が定期的に触る（ヘルスチェック。ADR 007）。
- プロジェクトの DB とユーザは、Terraform でなく VM の `afp` が作る。

## 理由

- 1 個しかないので、共有するしかない。1 ECPU・8 GB は小さなアプリを複数載せるには十分。
- 手元で同じ版の公式のコンテナを動かせ、本番と同じ条件を再現しやすい。
- Terraform を実行する Resource Manager からは、プライベート・サブネットの DB に届かない。VM からは届く。

## 採らなかった案

| 案 | 理由 |
|---|---|
| VM の上の DB（PostgreSQL など） | VM に状態が残り、ステートレスにできない |
| Autonomous Database | 7 日使わないと止まる。手元で同じものを動かすには専用のコンテナが要り、重い（推奨 4 CPU・8 GB）うえに一部の機能が欠ける |
