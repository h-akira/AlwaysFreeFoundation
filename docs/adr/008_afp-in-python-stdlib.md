# 008 `afp` は Python の標準ライブラリだけで書く

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）

## 背景

VM の上の基盤のコマンド `afp` は、プロジェクトの一覧（JSON）を読み、プロジェクトごとに分岐し、ファイルを書き、結果を確かめて戻すかを決める。OCI のサービス・コンテナ・DB を呼ぶ。

## 決定

- Python で書き、サブコマンドは `argparse` で作る。外部のライブラリは使わない（OCI の SDK も使わない）。
- OCI のサービスは OCI CLI を、コンテナは `docker compose` を、DB は `mysql` のクライアントを、`subprocess` から呼ぶ。

## 理由

- データの処理と分岐が読みやすく書ける。
- VM なしでテストを書ける（一覧の読み方・環境変数のファイルの作り方・戻すかどうかの判断）。
- 使い方は `--help` に置ける。文書に写さずに済む。
- 標準ライブラリだけなら、VM に最初から入っている python3 で動き、venv も pip も要らない。

## 採らなかった案

| 案 | 理由 |
|---|---|
| bash | JSON の扱いを `jq` に頼り、エラー処理とテストが書きにくい |
| Python と外部のライブラリ（OCI の SDK など） | VM に依存を入れる手順と、その版の管理が増える |
