# 007 基盤の監視は、VM からのヘルスチェック

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）
- 状態: 採用

## 背景

基盤として、VM と共有の DB が動いているかを知りたい。また、HeatWave の Always Free が使わないと止まるかは分からない（[references/oci-free-tier.md](../references/oci-free-tier.md)）。

## 決定

- VM が定期的に（1 時間ごと）HeatWave に問い合わせ、結果を OCI Monitoring に送る。失敗したときと、届かなくなったとき（VM が止まった）にアラームでメールする。
- アプリの監視は各プロジェクトの責任とし、基盤は道具も見本も用意しない。

## 理由

- 共有の DB を定期的に触ることと、VM・DB の死活の監視を 1 つで兼ねられる。
- 外に新しい入口を開けなくてよい。
- 自前の監視の仕組み（Prometheus など）は部品が増える。
