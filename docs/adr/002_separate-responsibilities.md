# 002 基盤の管理者とプロジェクトの管理者の責任を分ける

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）
- 状態: 採用

## 背景

基盤とその上のプロジェクトは、同じ人が作ることが多い。それでも、どちらが何を受け持つかが曖昧だと、基盤を変えるたびにプロジェクトが壊れ、プロジェクトを足すたびに基盤を直すことになる。

## 決定

- 基盤の管理者とプロジェクトの管理者の受け持ちを分け、両者がやり取りするものを約束として決める。同じ人が両方を担ってもよい。
- 基盤の操作（デプロイ・DB の削除・復元）を Web で受け付けない。

## 理由

- 境目が約束になる。基盤を変えてもプロジェクトは変わらず、プロジェクトを足しても基盤は変わらない。
- 基盤はプロジェクトの中身を知らないので、基盤を公開し、プロジェクトを非公開のまま載せられる。
- 障害のとき、どこを見ればよいかがすぐ分かる。
- 基盤の操作を Web で受け付けると入口が増え、そこが破られたときの影響が全プロジェクトに及ぶ。
- 共通のログイン（SSO）は作らず、各アプリが自分でログインを持つ。基盤がアプリの利用者を知らずに済む。
