# 012 開発中は削除保護を付けない

- 決めた日: 2026-11-09

## 背景

基盤を作っている間は、資源を作っては壊すのをくり返す。削除を防ぐ仕組み（Terraform の `prevent_destroy`・HeatWave の削除防止・コンパートメントを消せなくする設定）があると、そのたびに外す手間がかかる。

## 決定

- 基盤の開発中は、削除を防ぐ仕組みを一切付けない。
- 本物のデータを載せるときに、消えると困るもの（Vault・HeatWave・予約済みの IP・バケット）を `prevent_destroy` で守る。

## 理由

- 中身が空のうちは、消えても困らない。作って壊すのを速くくり返せる方が、開発が進む。
