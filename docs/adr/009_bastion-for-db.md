# 009 手元から DB に入るのは Bastion

- 決めた日: 2026-11-09 以前（記録: 2026-11-10）
- 状態: 採用

## 背景

DB はプライベート・サブネットにあり、外から届かない。保守のとき（調べもの・復元など）に、手元から DB に入る方法が要る。

## 決定

- OCI Bastion のポート転送を使う（[references/oci-bastion.md](../references/oci-bastion.md)）。

## 理由

- 無料で、DB の側に何も入れなくてよい。
- 使うときだけセッションを作り、時間が来れば切れるので、常に開いた入口が残らない。

## 採らなかった案

| 案 | 理由 |
|---|---|
| VM を踏み台にする（`ssh -L`） | VM が無いと DB に入れない。VM の ssh を開けておく必要がある |
| DB をパブリック・サブネットに置く | DB が外から届く場所に出る |
| VPN | 部品が増える |
