# 011 DB のパスワードは、URL で使える記号を必ず含める

- 決めた日: 2026-11-09
- 状態: 採用

## 背景

基盤はプロジェクトごとに DB のパスワードを作り、プロジェクトはそれを接続の URL に埋め込んで使う。最初は英数字だけで作るつもりだったが、HeatWave では `validate_password`（MEDIUM: 8 文字以上・大小英字・数字・記号を各 1 以上）が効いていて、英数字だけでは `CREATE USER` が ERROR 1819 になった（実測）。

## 決定

- 英字・数字と、URL でそのまま使える記号（`-`・`_`・`.`・`~`）だけで作り、記号を必ず含める。

## 理由

- 記号が無いとユーザを作れない。
- URL でそのまま使える記号に限れば、プロジェクトがエスケープせずに接続の URL に埋め込める。
