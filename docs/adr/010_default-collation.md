# 010 既定の照合順序は `utf8mb4_ja_0900_as_cs_ks`

- 決めた日: 2026-11-09
- 状態: 採用

## 背景

基盤がプロジェクトのデータベースを作るときの、既定の照合順序（文字の比べ方と並べ方）を決める必要がある。MySQL の既定（`utf8mb4_0900_ai_ci`）は、日本語の多くの文字を同じとみなす。HeatWave と手元の MySQL で、照合順序ごとに比べた（[references/mysql-notes.md](../references/mysql-notes.md) §2）。

## 決定

- 文字コードは `utf8mb4`、既定の照合順序は `utf8mb4_ja_0900_as_cs_ks`。
- 濁点・半濁点・ひらがなとカタカナ・大文字と小文字・小書きの文字を区別し、全角と半角だけを同じとみなす。並び順は日本語の順。

## 理由

- MySQL の既定は「ハ」「バ」「パ」も「は」「ハ」も同じとみなすので、一意制約で別の言葉がぶつかる。
- 全角と半角は、利用者が打ち分けを意識しないことが多いので、同じとみなす。

## 採らなかった案

| 案 | 理由 |
|---|---|
| `utf8mb4_0900_as_cs` | 全角と半角も区別する |
| `utf8mb4_ja_0900_as_cs` | ひらがなとカタカナを同じとみなす |
| `utf8mb4_bin` | 並び順が人の感覚と合わない |
